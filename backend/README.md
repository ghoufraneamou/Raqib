# AMMPS Capstone – Backend (Final Pipeline)

This backend exposes the full AMMPS document-validation pipeline as a REST API.

```
PDF / Image
   └─► OCR (EasyOCR)
         └─► LayoutLMv3 embeddings (optional)
               └─► YOLOv8 detection (signature / stamp / official header)
                     └─► Rule-based validation
                           └─► Dossier score + report
```

## 1. Features

- **Multi-file upload**: send several PDFs and/or images in a single request.
- **OCR** with EasyOCR to extract the text of each document.
- **LayoutLMv3** embeddings for layout-aware analysis (can be disabled for faster runtime).
- **YOLOv8** visual detection of three classes: `signature`, `stamp`, `official_header`.
- **Explainable rule-based validation** applied to the extracted text.
- **Dossier score and report** summarizing the validation of the whole file set.

## 2. Project Structure

```
backend/
├── app.py               # FastAPI app, exposes /health and /validate
├── pipeline.py          # Full pipeline (refactored from the Colab notebook)
├── train_yolo.py        # YOLOv8 training script
├── dataset_yolo.yaml    # Generated by train_yolo.py (absolute dataset paths)

└── weights/
```

The Roboflow dataset used for training is located in `stamps_signature_docs.v1i.yolov8/`.

## 3. Requirements

- **Python 3.12+** (recommended)
- `pip`
- Enough disk space for the model dependencies (PyTorch, EasyOCR, Transformers, Ultralytics)
- A GPU is **not** required; the pipeline runs on CPU

## 4. Installation

From the project root:

**macOS / Linux**
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell)**
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> If `requirements.txt` is inside the `backend/` folder, use `pip install -r backend/requirements.txt`.

## 5. Run the Server

From the project root (with the virtual environment activated):

```bash
uvicorn backend.app:app --host 0.0.0.0 --port 8000
```

Optional: disable LayoutLMv3 for a faster runtime.

```bash
# macOS / Linux
export AMMPS_DISABLE_LAYOUT=1

# Windows (PowerShell)
$env:AMMPS_DISABLE_LAYOUT = "1"
```

**Health check**

```
GET http://localhost:8000/health
```

Interactive API docs (provided automatically by FastAPI):

```
http://localhost:8000/docs
```

## 6. API Usage

### `POST /validate`

Validates one or more documents and returns the dossier score and report.

| Item        | Value                                    |
|-------------|------------------------------------------|
| URL         | `http://localhost:8000/validate`         |
| Method      | `POST`                                   |
| Body type   | `multipart/form-data`                    |
| Form key    | `files` (repeat the key for each file)   |
| Accepted    | PDF and image files (e.g. `.pdf`, `.jpg`)|

**Example with curl**

```bash
curl -X POST "http://localhost:8000/validate" \
  -F "files=@01_LETTRE_DEMANDE_realistic_scanned.pdf" \
  -F "files=@some_image.jpg"
```

**Example with Python**

```python
import requests

url = "http://localhost:8000/validate"
files = [
    ("files", open("01_LETTRE_DEMANDE_realistic_scanned.pdf", "rb")),
    ("files", open("some_image.jpg", "rb")),
]
response = requests.post(url, files=files)
print(response.json())
```

## 7. Configuration (Environment Variables)

### General

| Variable               | Default                    | Description                                         |
|------------------------|----------------------------|-----------------------------------------------------|
| `AMMPS_YOLO_WEIGHTS`   | `backend/weights/best.pt`  | Path to the YOLO weights file                       |
| `AMMPS_YOLO_CONF`      | `0.25`                     | Confidence threshold for YOLO detections            |
| `AMMPS_PDF_DPI`        | `200`                      | DPI used to render PDF pages to images before YOLO  |
| `AMMPS_DISABLE_LAYOUT` | not set                    | Set to `1` to disable LayoutLMv3 (faster runtime)   |

### Signature detection on low-quality scans

| Variable                      | Default  | Description                                              |
|-------------------------------|----------|----------------------------------------------------------|
| `AMMPS_YOLO_CONF_SIGNATURE`   | ~`0.14`  | Validation threshold for the `signature` class           |
| `AMMPS_YOLO_PREDICT_CONF`     | ~`0.08`  | Minimum confidence used at inference time                |
| `AMMPS_YOLO_ENHANCE`          | enabled  | Set to `0` to disable CLAHE image pre-processing         |

## 8. Training the YOLO Model

The Roboflow dataset is located in `stamps_signature_docs.v1i.yolov8/`.

On **Apple Silicon**, training on **MPS** can crash, so the script uses the **CPU** by default (stable).

```bash
cd backend
source .venv/bin/activate        # Python 3.12+ recommended
pip install -r requirements.txt
python train_yolo.py --epochs 35 --batch 12 --device cpu
```

At the end of training, the best weights are automatically copied to `backend/weights/best.pt`.

The file `backend/dataset_yolo.yaml` is generated automatically with absolute paths to the dataset.

---

## 9. Notes

- YOLO provides the **visual evidence** used to validate the **signature**, **stamp** and **official header** criteria.
- All other criteria are **explainable rules** applied to the extracted text.
- If the YOLO weights are missing, the pipeline still runs and falls back on **text-based hints**.
- Disabling LayoutLMv3 (`AMMPS_DISABLE_LAYOUT=1`) speeds up processing.

## 10. Troubleshooting

| Problem                                         | Solution                                                                                   |
|-------------------------------------------------|--------------------------------------------------------------------------------------------|
| `ModuleNotFoundError: backend`                  | Run `uvicorn backend.app:app` from the **project root**, not from inside `backend/`.       |
| Server is slow on the first request             | Models are loaded on first use (EasyOCR, LayoutLMv3, YOLO). Later requests are faster.     |
| Processing is too slow                          | Set `AMMPS_DISABLE_LAYOUT=1` and/or lower `AMMPS_PDF_DPI`.                                 |
| Signature not detected on a poor scan           | Lower `AMMPS_YOLO_CONF_SIGNATURE` or `AMMPS_YOLO_PREDICT_CONF`, and keep CLAHE enabled.    |
| Training crashes on Apple Silicon               | Use `--device cpu` (default in `train_yolo.py`), not MPS.                                  |
| YOLO results look empty                         | Check that `backend/weights/best.pt` exists or that `AMMPS_YOLO_WEIGHTS` points to it.     |
| Port 8000 already in use                        | Start the server on another port, e.g. `--port 8001`.                                      |
